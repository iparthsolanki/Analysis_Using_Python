# Pizza Sales Analysis

## Overview
This project is a comprehensive data analysis notebook focused on pizza sales performance using Python.  

The analysis explores sales trends, customer ordering behavior, product performance, and revenue insights to understand business performance and identify growth opportunities.

Using Exploratory Data Analysis (EDA), statistical analysis, and data visualization techniques, the project transforms raw sales data into meaningful business insights that can support decision-making in the food and restaurant industry.

---

## Business Problem
Understanding customer preferences and sales trends is essential for improving restaurant performance and maximizing revenue.

This project aims to analyze pizza sales data to answer important business questions such as:

- Which pizza categories generate the highest revenue?
- What are the most ordered pizza sizes and types?
- Which time periods generate maximum sales?
- Which products perform best and worst?
- How can sales insights improve business decisions?

---

The main objectives of this project are:

## Dataset Information

### Columns Included in the Dataset

- Pizza Name
- Pizza Category
- Pizza Size

- Order Date

- Unit Price
- Total Price

These columns are used to analyze sales patterns, customer preferences, revenue generation, and operational trends.
