# Global Happiness Report Analysis

## Overview
This project is a Python-based data analysis notebook focused on analyzing the Global Happiness Report dataset.  

The analysis explores how economic, social, and health-related factors affect happiness levels across different countries. The project uses Exploratory Data Analysis (EDA), statistical analysis, and data visualization techniques to discover meaningful insights from the dataset.

The notebook provides country-wise comparisons, correlation analysis, and graphical representations to understand the global happiness index more effectively.

---

## Objective
The main objectives of this project are:

- Analyze happiness scores across different countries
- Identify factors influencing global happiness
- Compare country-wise happiness rankings
- Study relationships between economic and social indicators
- Visualize trends and patterns using charts and graphs
- Practice data analysis and visualization using Python

---

## Dataset Information
The dataset contains information related to happiness scores and socio-economic indicators of multiple countries around the world.

### Columns Included in the Dataset
- Country Name
- Regional Indicator
- Ladder Score (Happiness Score)
- Logged GDP per Capita
- Social Support
- Healthy Life Expectancy
- Freedom to Make Life Choices
- Generosity
- Perceptions of Corruption
- Positive Affect
- Negative Affect

These factors are analyzed to understand how they contribute to the happiness level of a country.
