# AI Jobs Analysis Project (Python Notebook)

## Overview
This project is an AI Jobs Analysis notebook developed using Python.  
It focuses on analyzing job-related data in the field of Artificial Intelligence to identify trends, skills, salaries, and industry insights.

---

## Objective
The main objective of this project is to:
- Analyze AI job market trends
- Explore salary distributions and job roles
- Identify in-demand skills and technologies
- Generate meaningful insights through data analysis

---

## Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- AI job market insights
- Salary and role-based analysis
- Data visualization using charts and graphs
- Structured notebook workflow

---

## Tools & Technologies
- Python
- Jupyter Notebook (.ipynb)
- Pandas
- NumPy
- Matplotlib / Seaborn

---

## Project File
- ai_jobs.ipynb → Main notebook file

## How to Use
1. Download the .ipynb file
2. Open it using Jupyter Notebook or Google Colab
3. Run all cells step-by-step to view the analysis and insights
