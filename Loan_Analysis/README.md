# Loan Analysis Project

## Overview
This project is a Python-based data analysis notebook focused on loan application and loan approval analysis.  

The project analyzes applicant information such as income, education, employment status, loan amount, credit history, and property area to identify patterns and factors affecting loan approval decisions.

Using Exploratory Data Analysis (EDA), statistical analysis, and data visualization techniques, the notebook generates meaningful insights from the loan dataset.

---

## Objective
The main objectives of this project are:

- Analyze loan application data
- Identify factors influencing loan approval status
- Study applicant demographics and financial details
- Perform Exploratory Data Analysis (EDA)
- Visualize trends and relationships in the dataset
- Practice data analysis using Python

---

## Dataset Information
The dataset contains loan applicant and financial information.

### Columns Included in the Dataset
- Loan_ID
- Gender
- Married
- Dependents
- Education
- Self_Employed
- ApplicantIncome
- CoapplicantIncome
- LoanAmount
- Loan_Amount_Term
- Credit_History
- Property_Area
- Loan_Status

These columns are used to analyze applicant profiles, income patterns, loan details, and approval status.
