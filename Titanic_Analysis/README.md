# Titanic Survival Analysis

## Overview
This project is a Python-based data analysis notebook focused on the Titanic dataset.  

The project analyzes passenger information such as age, gender, passenger class, fare, and survival status to identify the factors that influenced survival during the Titanic disaster.

Using Exploratory Data Analysis (EDA), data visualization, and statistical analysis techniques, the notebook uncovers meaningful insights and patterns from the dataset.

---

## Objective
The main objectives of this project are:

- Analyze Titanic passenger data
- Identify factors affecting passenger survival
- Compare survival rates across different categories
- Perform Exploratory Data Analysis (EDA)
- Visualize trends and relationships in the dataset
- Practice data analysis using Python

---

## Dataset Information
The dataset contains passenger-related information from the Titanic disaster.

### Columns Included in the Dataset
- PassengerId
- Survived
- Pclass
- Name
- Sex
- Age
- SibSp
- Parch
- Ticket
- Fare
- Cabin
- Embarked

These columns are used to analyze passenger demographics, travel class, and survival patterns.
